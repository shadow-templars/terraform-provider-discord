# Security Policy

## Supported versions

Only the latest `3.x` release receives fixes. Older versions are not maintained.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's [Report a vulnerability](https://github.com/shadow-templars/terraform-provider-discord/security/advisories/new) flow rather than opening a public issue.

We will acknowledge the report and address confirmed issues as capacity allows. There is no formal response-time guarantee.
